# Star Wars: Thrawn Trilogy Add-on

This is an original fan total‑conversion for Battle for Wesnoth targeting versions **1.19** and **1.20**. It creates a new Star Wars setting based on the Thrawn Trilogy but uses only original content.

**Important:** No copyrighted prose, dialogue, art, music, audio, or proprietary game assets are copied. All code, text, and assets in this add‑on are created from scratch.
